# JLPT Prep 準

A very simple, offline-friendly app for **covering** every JLPT **N4, N3 and N2** kanji and
vocabulary card *before* testing yourself. No quizzes, no scores.

Pick a level → pick **Kanji** or **Vocabulary** → scroll the numbered list → tap a card to read its
one-page lesson (meaning, readings with **romaji**, words, forms, tips). **Long-press** a row (or
right-click on desktop) to mark it **Pending · Review · Done** — the small square at the right edge
shows its status. When every square in a deck is green, that deck is complete.

**Live app:** https://sangeeth-subramoniam.github.io/JLPT_prep/ — open it once, then *Add to Home
Screen*; it works fully offline afterwards. Progress stays in your browser (Settings → Export to
back it up or move it).

## Run locally
```bash
python3 -m http.server 8765   # then open http://localhost:8765
```

## Tests
```bash
node --test
```

## Regenerate the decks
The decks are generated from the committed data of the sister project Kanji Commute
(`../japanese_learning_bot/data`). Card numbers are frozen — the generator refuses to renumber.
```bash
node tools/build_data.mjs [--source ../japanese_learning_bot/data] [--check]
```
